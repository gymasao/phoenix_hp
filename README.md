# PHOENIX Baseball Club

PHOENIX 野球チームの公式サイト用スターターテンプレートです。

## ページ構成（予定）

- `/` — トップページ、直近試合、チーム成績、打撃リーダー
- `/results` — 試合結果・スコア詳細
- `/stats` — 打撃・投手・守備の個人成績
- `/players` — 選手紹介
- `/about` — チーム紹介・活動方針・問い合わせ

現在はトップページを実装し、試合結果や成績はサンプルデータで表示しています。

## Local development

```bash
pnpm install
pnpm dev
```
